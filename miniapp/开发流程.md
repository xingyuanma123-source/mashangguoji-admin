# 小程序开发流程入口

日常操作统一维护在 [协作流程](https://github.com/xingyuanma123-source/mashangguoji-admin/blob/codex/collaboration-complete/docs/collaboration-guide.md)，避免多份步骤互相矛盾。

- 第一次启动：[快速开始](QUICK_START.md)。
- 确认连接哪个库：[数据库配置](DATABASE_CONFIG.md)。
- 看仓库和分支怎么用：[新手指南](../docs/START-HERE.md)。
- 数据库迁移：[台账与 SOP](../docs/migrations-ledger.md)。

开发和测试使用 staging；代码版本、构建配置、数据库和部署环境都需要明确区分。测试账号向负责人获取，不在公开文档里提供账号密码。

发布正式小程序需负责人确认、staging 验收及微信平台发布流程。不要把“已 push”当成“已上线”。原来的详细步骤可从 Git 历史查看，不再作为当前操作入口。
